# 💄 Projeto Loja de Maquiagem

## 📌 Descrição do Projeto

Este projeto consiste no desenvolvimento de um site para uma loja de maquiagem. A proposta é criar uma página organizada e fácil de usar, onde os usuários possam conhecer os produtos disponíveis e encontrar informações sobre a loja.

O projeto será desenvolvido por etapas, começando pela documentação, organização dos arquivos e criação dos wireframes, para depois iniciar a programação em HTML, CSS e JavaScript.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma loja de maquiagem virtual com uma interface simples, bonita e organizada, facilitando a visualização dos produtos e a navegação pelo site.

## 📋 Escopo do Projeto

O projeto contará inicialmente com:

* Página inicial da loja;
* Apresentação dos produtos;
* Imagens dos produtos;
* Organização dos produtos por categorias;
* Área de informações da loja;
* Estrutura visual baseada nos wireframes;
* Desenvolvimento utilizando HTML, CSS e JavaScript.
